\# Mentor: Find your way to the peak.



A Web Technologies course project that connects students with relevant mentors/alumni for academic and career guidance.



\## Technologies



\* HTML

\* CSS

\* JavaScript

\* PHP

\* MySQL

\* XAMPP



\## Project Setup



1\. Clone the repository into the XAMPP `htdocs` directory.

2\. Start \*\*Apache\*\* and \*\*MySQL\*\* from XAMPP.

3\. Create a MySQL database named `mentor`.

4\. Import `database/schema.sql`.

5\. Import `database/seed.sql`.

6\. Open the project at:



```text

http://localhost/Mentor/

```



\## Demo Accounts
